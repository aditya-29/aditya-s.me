About

I’m an Applied Scientist at Amazon AGI, working on Nova foundation models. My focus is on model training and evaluation.

Previously, I was a Machine Learning Engineer (GenAI) on the CoreLLM team at ServiceNow. My published work spans API retrieval for code generation, evaluation of video-language models, and machine learning for healthcare.
